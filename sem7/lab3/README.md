# Краевая задача В4

Решаем \(y''=a(y^3-y)\) при \(y(-10)=y(10)=\sqrt{2}\) для \(a\) от \(100\) до \(10^6\). Используем равномерную сетку и схему Нумерова четвёртого порядка. Система для поправки Ньютона трёхдиагональная. Эталонный решатель использует прогонку.

По симметрии решаем задачу на \([0,10]\). Условие \(y'(0)=0\) задаём зеркальным узлом \(y_{-1}=y_1\). Каждый MPI-ранг циклической редукцией исключает внутренние уравнения своего блока. Ранги обмениваются оставшимися граничными уравнениями, решают малую систему и восстанавливают свои поправки.

## Сборка и запуск

Из корня репозитория, с доступным в окружении MPI.

```bash
cmake -S sem7/lab3 -B sem7/lab3/build -DCMAKE_BUILD_TYPE=Release
cmake --build sem7/lab3/build -j
ctest --test-dir sem7/lab3/build --output-on-failure

mpirun -n 4 sem7/lab3/build/boundary_lab --a 100 --intervals 12800 --output solution.csv
mpirun -n 1 sem7/lab3/build/boundary_lab --solver thomas --full --a 100 --intervals 25600
```

`--intervals` задаёт число интервалов на решаемом отрезке. По умолчанию используется половина отрезка и подбирается шаг из условия \(h\sqrt a\le0{,}1\). CSV с решением содержит полный отрезок.

## Замеры

```bash
python3 sem7/lab3/scripts/benchmark.py --binary sem7/lab3/build/boundary_lab \
    --output sem7/lab3/results/run --pin
python3 sem7/lab3/scripts/plot.py sem7/lab3/results/run --output sem7/lab3/results/run/plots
```

Для привязки `--pin` используется Open MPI и `taskset`. Последовательный и параллельный расчёты каждого \(a\) идут на одинаковой сетке. Скрипт выбирает числа MPI-рангов, при которых на ранг приходится 400–4000 неизвестных. Время учитывает итерации Ньютона и MPI-обмены в них. Подготовка начального приближения, вывод решения и проверки идут отдельно. `verification.csv` содержит расхождения с прогонкой, с полным отрезком и с сеткой вдвое мельче.

Ускорение на графике вычисляется из медиан десяти замеров. В `timings.csv` сохраняются все повторы, а сводка содержит также среднее и стандартное отклонение.
